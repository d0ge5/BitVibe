# Beats folder

Drum beats placed here (WAV, MP3, AIFF, FLAC or OGG) show up in the **library** list of BitVibe's DRUMS tab when
you run a build made from this source tree. Installed copies of BitVibe look in `Documents/BitVibe/Beats`
instead (the list shows both).

Audio files in this folder are ignored by git, so your own loops are never committed to the public
repository by accident. The DRUMS tab also has a built-in **Demo beat** that needs no file.
