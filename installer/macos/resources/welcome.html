Ottoclone

A bitcrusher, ladder filter, stutter and 6-step sequencer effect for guitar and synths, modelled on the behaviour of a well-known hardware pedal.

This is an independent, unofficial project. It is not affiliated with, endorsed by or sponsored by Meris.

The next screens let you choose which formats to install: VST3, Audio Unit and a Standalone app.

Ottoclone is free software released under the GNU Affero General Public License v3. The source code is at github.com/d0ge5/ottoclone.
